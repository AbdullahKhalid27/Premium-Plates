## Summary

Phase 3 now brings the registration preview, finish inspection and itemised estimate together in the workshop. The catalogue and lookbook feed the same configuration used by the bag.

| Entry point | Customer action | Result |
| --- | --- | --- |
| Home | Type a registration | The hero plate and builder share the registration. |
| Builder | Select a tray, rotate the plate or move its light | A bumper-mounted specimen shows the selected profile and lettering. The price tray shows the estimate. |
| Collection and lookbook | Expand a style and use it in the builder | The builder opens with that style selected. |
